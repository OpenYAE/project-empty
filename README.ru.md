# Project Empty

## Что это

*You Are Empty* — шутер 2006 года от киевских студий Digital Spray Studios и Mandel ArtPlains
(издатели — 1С в СНГ, Atari на западе), так и не получивший продолжения. Его движок, DS2 Engine,
закрыт, исходников нет. Project Empty — сообщество, которое разбирает оригинал до винтика и
пересобирает его наследие в открытых формах:

- **новый движок**, который запускает оригинальные ресурсы на современном стеке (C++20, SDL3,
  OpenGL 4.5, Jolt, Lua 5.4) — Windows и Linux из одного кода;
- **SDK** — редактор уровней и конвертеры в открытые форматы (glTF, OBJ): моддинг и Blender;
- **спецификации игровых форматов**, восстановленные реверс-инжинирингом;
- **каталог PBR-материалов** сообщества поверх оригинальных текстур — одна работа моддера,
  результат и в нативном рендере, и в RTX Remix;
- **графические моды для оригинальной игры**: `yae-dlss5` приносит DLSS 5 Neural Rendering в
  оригинальную 32-битную OpenGL-сборку.

Мы не аффилированы с правообладателями и не распространяем игровые ресурсы. Репозитории
лежат в организации [OpenYAE](https://github.com/OpenYAE) на GitHub.

## Кто это пишет

Бо́льшую часть кода и документов Project Empty написали ИИ-агенты — Claude от Anthropic (через
Claude Code) и Codex от OpenAI — под руководством сопровождающего проекта: он ставит цели, играет
в оригинал и в новый движок бок о бок, записывает эталонные сессии, решает каждый вопрос
поведения и картинки и принимает работу. Мы этого не скрываем: поэтому в репозиториях лежат
инструкции для агентов (`CLAUDE.md`, навыки), и поэтому каждое изменение сдаётся с замерами и
гейтом, а не с описанием. Вклад — руками или с агентом — идёт по одним правилам:
[CONTRIBUTING.md](CONTRIBUTING.md).

## Рабочее пространство

Этот репозиторий — корень рабочего пространства: README экосистемы, `CONTRIBUTING.md`, `CLAUDE.md` для
агентов и `bootstrap.sh`, который клонирует в него остальные репозитории. Каждый из них — отдельный
репозиторий со своим гейтом. Гейт движка — `build.sh --check`, его скрипты, `render.cfg` и навыки агентов —
живут в движке, и его команды запускаются из `yae-engine/`. Движок находит соседей рядом с собой
(`../yae-game/gameres`, `../yae-materials/export/engine/catalog.yaemat`, `../yae-sdk/sdk-desktop`), портал
собирает из них разделы (`sources.json`), а отсутствующий сосед пропускается с предупреждением.

```
project-empty/             этот репозиторий: README, CLAUDE.md, bootstrap.sh
├── yae-engine/            движок и его гейты    ┐
├── yae-sdk/               SDK                   │
├── yae-materials/         каталог материалов    │ их клонирует bootstrap.sh (Release 1)
├── yae-docs/              портал                │
├── yae-research/          заметки исследования  │
├── yae-viewer/            просмотрщик           ┘
├── yae-QindieGL/  yae-dcc-plugins/  yae-level-converter/  yae-dlss5/     bootstrap.sh --all
└── yae-game/              ваша копия игры (не в git; gameres ≈ 8.5 ГБ)
```

## Возможности движка

- Полная загрузка оригинальных ресурсов: уровни, модели, анимации, текстуры, скрипты, звук,
  видео — ничего не нужно конвертировать.
- Игровая логика на Lua, совместимая с прототипами оригинала: ИИ, FSM-поведение, триггеры,
  катсцены, скриптовые сцены уровней.
- Физика Jolt по правилам ODE 0.5 оригинала: шарниры, тросы, конвейеры, лифты, рэгдоллы
  (эталон — уровень мясокомбината с краном).
- Читает **оригинальные сохранения** `.ds2gsf` и пишет свои.
- Меню, назначения клавиш и файлы настроек оригинала; ролики декодируются внутри движка
  (libavcodec из FFmpeg); консоль разработчика; самотесты при старте; гейт из 24 уровней (smoke
  плюс пиксельное сравнение); CI на Linux и Windows.
- Windows и Linux из одного кода (SDL3).

## Быстрый старт

> Нужны файлы вашей копии игры (лицензионной или из переиздания). Ресурсы игры не входят ни в
> один репозиторий.

**Чтобы играть:** скачайте пакет для Linux или Windows со страницы
[релизов движка](https://github.com/OpenYAE/yae-engine/releases), распакуйте в папку игры (рядом с
`gameres`) и запустите `run.sh` или `run.bat`; остальное — в `README.ru.txt` пакета.

**Чтобы собирать и работать** — с нуля до запущенного уровня:

```bash
git clone https://github.com/OpenYAE/project-empty && cd project-empty
bash bootstrap.sh                  # клонирует движок, SDK, каталог, портал, заметки, просмотрщик
cp -r "/путь/к/You Are Empty" yae-game    # ваша копия игры: папка, в которой лежит gameres/
(cd yae-sdk/sdk-desktop && npm install)   # парсеры SDK: гейт сверяет с ними парсеры движка
cd yae-engine                      # команды движка запускаются отсюда
bash build.sh                      # движок (пресет dev): один раз скачивает и собирает зависимости
bash run_level.sh -map med1        # уровень; ./build/yae-engine --root ../yae-game/gameres — меню
bash build.sh --check              # все гейты, перед коммитом
```

Что нужно для сборки (CMake 3.25+, Ninja, GCC 13+ или Clang 17+, системные пакеты SDL3) — в
[README движка](https://github.com/OpenYAE/yae-engine#readme); `CLAUDE.md` — карта рабочего пространства.

SDK:

```bash
cd yae-sdk && npm install
npx tsx index.js model -i actor.ds2md -o out/actor.glb    # модель со скелетом и анимациями
npx tsx index.js level -i map.ds2 -o out/level            # уровень в OBJ
```

## Отношение к официальному переизданию

Переиздание в Steam — хорошая новость: оно возвращает игре аудиторию, и именно на его копии
будут работать наши проекты. Мы занимаемся другим: открытый код, Linux, инструменты моддинга и
то, что переиздание дать не может. Наши проекты дополняют его, а не конкурируют с ним.

  аффилирован с ними и ни на что не претендует.
- **Реверс-инжиниринг.** Декомпилированный код, бинарники оригинала и проект Ghidra живут в
  приватном рабочем пространстве и не публикуются. Публичные репозитории содержат только
  результаты анализа: описания форматов, интерфейсов и поведения. Ссылка вида `FUN_0f8a7940`
  (адрес функции в оригинальном бинарнике) или `+0xa34` (смещение поля) — указатель на
  доказательство, который любой проверит своей копией игры и дизассемблером, а не сам код.
