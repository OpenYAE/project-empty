# Project Empty

An independent open-source community initiative — the **YAE-Collective** — building a modern engine,
an SDK and modding tools for **You Are Empty** (2006). Everything runs on the files of your own copy of
the game; no assets are distributed and no decompiled code is published.

| | | |
|---|---|---|
| ![kolhoz: the yard](images/kolhoz-yard.jpg) | ![met6: the metro car](images/met6-metro-car.jpg) | ![lastzlo: a tunnel under a lamp](images/lastzlo-tunnel.jpg) |

**To play:** the engine's packages for Windows and Linux are on its
[releases](https://github.com/OpenYAE/yae-engine/releases) — unpack into your game's folder and run.
**To build or contribute:** start at [project-empty](https://github.com/OpenYAE/project-empty).

| Start here | |
|---|---|
| [project-empty](https://github.com/OpenYAE/project-empty) | the ecosystem overview, contributing guide, workspace bootstrap |
| [yae-engine](https://github.com/OpenYAE/yae-engine) | the engine: C++20, SDL3, OpenGL 4.5, Jolt, Lua 5.4; Windows and Linux |
| [yae-sdk](https://github.com/OpenYAE/yae-sdk) | the level editor, format library, converters and browser viewer |
| [yae-materials](https://github.com/OpenYAE/yae-materials) | the community PBR material catalog |
| [yae-viewer](https://github.com/OpenYAE/yae-viewer) | the browser viewer for levels and models ([live](https://openyae.github.io/yae-viewer/)) |
| [yae-docs](https://github.com/OpenYAE/yae-docs) | the documentation portal (EN · RU · UK) |
| [yae-research](https://github.com/OpenYAE/yae-research) | what is known about the original DS2 Engine |

Also: [yae-level-converter](https://github.com/OpenYAE/yae-level-converter) (the C++ OBJ converter),
[yae-dcc-plugins](https://github.com/OpenYAE/yae-dcc-plugins) (3ds Max / Maya, unmaintained),
[yae-QindieGL](https://github.com/OpenYAE/yae-QindieGL) (OpenGL → D3D9 shim for the original),
[yae-dlss5](https://github.com/OpenYAE/yae-dlss5) (DLSS 5 Neural Rendering for the original).

Most of the code was written by AI agents — Claude and Codex — under the maintainer's direction;
[project-empty](https://github.com/OpenYAE/project-empty#who-writes-it) says how the work is done.

*You Are Empty* and the related marks belong to their owners; Project Empty is not affiliated with them.
