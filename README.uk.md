## Що це

*You Are Empty* — шутер 2006 року від київських студій Digital Spray Studios та Mandel ArtPlains
(видавці — 1С у СНД, Atari на заході), який так і не отримав продовження. Його рушій, DS2 Engine,
закритий, вихідних кодів немає. Project Empty — спільнота, яка розбирає оригінал до гвинтика й
перезбирає його спадщину у відкритих формах:

- **новий рушій**, що запускає оригінальні ресурси на сучасному стеку (C++20, SDL3, OpenGL 4.5,
  Jolt, Lua 5.4) — Windows і Linux з одного коду;
- **SDK** — редактор рівнів і конвертери у відкриті формати (glTF, OBJ): моддинг і Blender;
- **специфікації ігрових форматів**, відновлені реверс-інжинірингом;
- **каталог PBR-матеріалів** спільноти поверх оригінальних текстур — одна робота моддера,
  результат і в нативному рендері, і в RTX Remix;
- **графічні моди для оригінальної гри**: `yae-dlss5` приносить DLSS 5 Neural Rendering в
  оригінальну 32-бітну OpenGL-збірку.

Ми не афілійовані з правовласниками й не поширюємо ігрові ресурси. Репозиторії лежать в
організації [OpenYAE](https://github.com/OpenYAE) на GitHub.

## Хто це пише

Більшу частину коду й документів Project Empty написали ШІ-агенти — Claude від Anthropic (через
Claude Code) і Codex від OpenAI — під керівництвом супроводжувача проєкту: він ставить цілі, грає
в оригінал і в новий рушій пліч-о-пліч, записує еталонні сесії, вирішує кожне питання поведінки й
картинки та приймає роботу. Ми цього не приховуємо: тому в репозиторіях лежать інструкції для
агентів (`CLAUDE.md`, навички), і тому кожна зміна здається із замірами та гейтом, а не з описом.
Внесок — руками чи з агентом — іде за одними правилами: [CONTRIBUTING.md](CONTRIBUTING.md).

## Швидкий старт

> Потрібні файли вашої копії гри (ліцензійної або з перевидання). Ресурси гри не входять до
> жодного репозиторію.

**Щоб грати:** завантажте пакет для Linux або Windows зі сторінки
[релізів рушія](https://github.com/OpenYAE/yae-engine/releases), розпакуйте в теку гри (поруч із
`gameres`) і запустіть `run.sh` або `run.bat`; решта — у `README.txt` пакета.

**Щоб збирати й працювати** — з нуля до запущеного рівня:

```bash
git clone https://github.com/OpenYAE/project-empty && cd project-empty
bash bootstrap.sh                  # клонує рушій, SDK, каталог, портал, нотатки, переглядач
cp -r "/шлях/до/You Are Empty" yae-game    # ваша копія гри: тека, в якій лежить gameres/
cd yae-engine                      # команди рушія запускаються звідси
bash build.sh                      # рушій (пресет dev): один раз завантажує й збирає залежності
bash run_level.sh -map med1        # рівень
```
